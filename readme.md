# MusicFree

**中文** 

该项目基于https://github.com/maotoumao/MusicFree   dev分支 二开

优化功能
优化功能

1.点击播放列表立即下载到 设置中的下载目录，歌单列表会优先查找下载目录中文件名包含 "歌曲名@作者"，防止插件源失效导致歌曲失效
2.歌曲中加入"换源"功能，可以把歌曲源换成其他的插件
3.横屏模式下，显示播放列表在右侧，方便安装平板或车机，原版安装到大屏里面 太丑了
4.设置增加了一个歌曲文件webdav功能，可备份和恢复
5.我的歌单 点击即下载歌曲文件到你设置的下载目录，歌单加了个数字角标，显示你下载目录下的文件列表，可以删除重复歌曲
